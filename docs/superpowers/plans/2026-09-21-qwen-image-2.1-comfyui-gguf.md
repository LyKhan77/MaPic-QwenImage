# Pivot Qwen-Image 2.1: ComfyUI + GGUF di gspe-ai2

> **For agentic workers:** Plan ini menggantikan Fase 1–4 pada `2026-09-21-qwen-image-2.1-migration.md` untuk mesin inference. Frontend dan backend **tidak berubah** — kontrak API inference server dipertahankan.

**Goal:** Menjalankan Qwen-Image 2.1 di `gspe-ai2` (2× RTX 5080 16 GB, RAM tersisa 29 GB) dengan ComfyUI + ComfyUI-GGUF sebagai engine, dibungkus ulang oleh `qwen_image_server` agar backend dan frontend yang sudah ada tetap bekerja tanpa perubahan.

**Kenapa pivot:** bobot bf16 resmi 31 GB tidak muat di VRAM (29,4 GiB) maupun RAM yang tersedia. Tiga jalur diffusers sudah dicoba dan gagal: (1) spill CPU → device mismatch di text encoder Qwen3-VL, (2) bf16 penuh → OOM, (3) bitsandbytes 8-bit → text encoder berakhir di device `meta`. GGUF menghilangkan ketiga masalah itu: Q8_0 (7,6 GB) + text encoder int8 (9,35 GB) + VAE (0,68 GB) ≈ 17,6 GB.

**Tech Stack:** ComfyUI (commit `e638023`) + ComfyUI-GGUF fork `leejet` (commit `edd981b`) · GGUF Q8_0 · text encoder int8 · VAE bf16 · FastAPI facade.

## Graph API-format (T2I)

Bentuk inilah yang dikirim ke `POST /prompt`. Node diambil dari template resmi `image_qwen_image_2_1_t2i.json`, dengan `UNETLoader` diganti `UnetLoaderGGUF`.

```python
{
  "1": {"class_type": "UnetLoaderGGUF", "inputs": {"unet_name": "qwen-image-2.1-Q8_0.gguf"}},
  "2": {"class_type": "CLIPLoader", "inputs": {
            "clip_name": "qwen3vl_8b_int8_convrot.safetensors",
            "type": "qwen_image", "device": "default"}},
  "3": {"class_type": "VAELoader", "inputs": {"vae_name": "qwen_image_2.1_vae_bf16.safetensors"}},
  "4": {"class_type": "TextEncodeQwenImage21", "inputs": {
            "clip": ["2", 0], "prompt": PROMPT, "negative_prompt": NEG, "resolution": RESOLUTION}},
  "5": {"class_type": "EmptyLatentImage", "inputs": {"width": W, "height": H, "batch_size": 1}},
  "6": {"class_type": "KSampler", "inputs": {
            "model": ["1", 0], "positive": ["4", 0], "negative": ["4", 1],
            "latent_image": ["5", 0], "seed": SEED, "steps": STEPS,
            "cfg": CFG, "sampler_name": "euler", "scheduler": "simple", "denoise": 1.0}},
  "7": {"class_type": "VAEDecode", "inputs": {"samples": ["6", 0], "vae": ["3", 0]}},
  "8": {"class_type": "SaveImage", "inputs": {"images": ["7", 0], "filename_prefix": "mapic"}},
}
```

Catatan penting dari catatan resmi template:

- `cfg` tetap `1` kecuali ada negative prompt — persis semantik `true_cfg_scale` yang sudah ada di kode kita (`_effective_cfg`).
- `steps` 40–50 untuk jalur resmi dengan sampler `euler`.
- 2K = 2048×2048 (4 megapiksel), kelipatan 32.
- RGBA: prompt dibungkus `"This is an RGBA format image with transparency. <deskripsi>. The image has an alpha channel and a transparent background."`, simpan PNG.

## Hasil terukur di gspe-ai2 (2026-09-21)

Semua file model lolos verifikasi SHA256 terhadap `SHA256SUMS` repo. Gate Task 2 lulus, lalu facade diuji end-to-end:

| Skenario | Waktu | Catatan |
|---|---|---|
| T2I 1K / 40 step | 32,2 s | 1,37 it/s saat difusi |
| T2I 1K / 40 step / CFG 2.0 + negative | 63,4 s | CFG ~2x, sesuai teori |
| I2I 1K / 40 step / 1 referensi | 49,8 s | +17 s per referensi |
| I2I 1K / 40 step / 3 referensi | 83,5 s | |
| Warmup (load) | 2,9 s | saat model masih hangat di VRAM ComfyUI |

VRAM puncak: **~14,4 GB di satu kartu** (GPU 1 praktis idle). Semua keluaran 1024x1024 RGBA.

**Catatan penting:** server ini juga menjalankan `llama-server` (intercon-agent, Qwen3.5) lewat PM2 yang memakai **27,6 GB dari 32 GB VRAM**. Keduanya tidak bisa hidup bersamaan; percobaan 2K saat VRAM terbagi membuat mesin perlu reboot. Karena itu `QWEN_MAX_RESOLUTION=1024` dipasang sebagai batas di host ini dan permintaan 2K ditolak dengan pesan error, bukan OOM.

## Risiko terbuka

- **`--lowvram` vs `--highvram`:** teks encoder int8 (9,35 GB) idealnya di RAM, DiT di VRAM. Bila ComfyUI menaruh keduanya di VRAM, 17,6 GB masih muat di 2×16 GB tetapi menyisakan sedikit ruang untuk aktivasi 2K. Task 2 Step 4 yang menentukan.
- **2K belum terbukti** di 16 GB per GPU; bila OOM, batasi `QWEN_MAX_RESOLUTION=1024`.
- **Bobot diffusers 31 GB sudah dihapus** dari cache HF `gspe-ai2` (jalur diffusers terbukti gagal di host ini). Bila nanti dijalankan di server tri-GPU, bobot itu harus diunduh ulang — cache tadi ada di mesin yang berbeda sehingga memang tidak bisa dipakai ulang.
- **Tidak ada safety filter** di jalur ini. App ini multi-user, jadi moderasi keluaran ada di sisi aplikasi — belum ada mekanisme apa pun untuk itu.
